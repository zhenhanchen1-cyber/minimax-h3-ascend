# 九宫格图生视频教程（复刻 freedidi 25535 的玩法）

> 原理：一张 3×3 分镜图 = 9 个镜头。每个格子切出来 → 喂给 H3 做图生视频（每格配一段提示词）→ 得到 9 段同一角色的短片 → 剪映按顺序拼成故事。

---

## 第 1 步：生成九宫格分镜图

在**任何生图工具**（即梦、ChatGPT、纳米 AI 都行）生成一张 3×3 九宫格。提示词模板（自己改角色和场景）：

```
生成一张 3x3 九宫格分镜图，九个画面必须是同一个角色、同一套服装、同一场景：
一位穿浅蓝和服的年轻女子，日式木屋室内，暖色晨光，写实电影质感。
9 个镜头依次为：
1 特写：她站在木楼梯上回眸；
2 全景：她跪坐叠被子，男人坐在门边看她；
3 特写：男人惊讶的表情；
4 近景：她低头浅笑；
5 近景：两人脸凑近对视；
6 特写：接吻；
7 全景：两人相拥；
8 特写：她靠在对方肩上，看向镜头；
9 空镜：桌上茶碗，窗外晨光。
画面比例 16:9，人物面部在各格中保持完全一致，电影打光，胶片质感。
```

要点：
- **每格写清楚景别**（特写/全景/近景）和动作，这样后面每格的提示词好写
- 强调"同一角色、同一服装"，脸崩了后面全废
- 竖屏剧情就选 9:16

## 第 2 步：切成 9 张小图

我给你写好了工具。在本机 CMD/PowerShell 里：

```bash
cd <本地目录>
python 切九宫格.py 你的九宫格图.png
```

会自动生成 `xxx_cells/cell_1.png ~ cell_9.png`（从左到右、从上到下编号）。

## 第 3 步：加载图生视频工作流

浏览器打开 http://127.0.0.1:8188（记得先建 SSH 隧道，命令见《MiniMax-H3出片操作手册》）。

你截图里那个工作流是**纯文生视频**模板（有个"空闲Latent图像"节点），它不能吃图片。
做九宫格转视频，打开左侧 **Workflows → minimax-h3 → fl2va_8steps_lora_int8_2npu.json**。

这份工作流里有 **「First Frame」** 节点——这就是放格子图的地方。

## 第 4 步：逐格生成（每格 90 秒~3 分钟）

对每一个格子：

1. **First Frame 节点** → choose file to upload → 选 `cell_1.png`
2. **Input Text (Prompt)** → 写这个镜头里发生的事。模板：

```
以输入图片作为第一帧，保持人物长相、服装、场景完全一致。
[这里写这个镜头的动作，例如：她站在木楼梯上缓缓回头，
镜头缓慢推进她的面部，发丝随动作轻晃。
声音：木质楼梯的吱呀声，窗外鸟鸣，轻柔的配乐。]
不要字幕、水印、人物变形、突然切换镜头。
```

3. **Last Frame 连线断开**（只用首帧）
4. 点 **Run**，等出片
5. 把 First Frame 换成 cell_2，提示词换成镜头 2 的……重复 9 次

**省事技巧**：改完提示词点 Run 前先 `Ctrl+S` 保存工作流，这样 9 个镜头可以存 9 份，坏了随时重跑某一格。

## 第 5 步：剪映拼接

1. 9 段视频从服务器拉回本地（或界面里右键 → Save）
2. 打开剪映 → 导入 9 段 → 按编号排好
3. 段与段之间加 0.2~0.5s 叠化转场（掩盖细微的脸部跳变）
4. 配 BGM（可选，因为每段已带环境音），导出

---

## 想让角色更稳？进阶玩法

- **Ref2VA 工作流**（角色一致性最强）：Workflows → minimax-h3 → `ref2va_8steps_lora.json`，主模型换 `minimax_h3_ref2va_pruned_int8_convrot.safetensors`，可以喂多张同一角色的参考图
- 九宫格生成时多强调"同一人物"，脸崩的格子直接重新生成该格
- 首尾帧法：把上一段的最后一帧导出，接到下一段的 First Frame，衔接最顺滑
